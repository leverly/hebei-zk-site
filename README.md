# 河北中考领航

把《义务教育英语课程标准（2022 年版）》三级词汇与河北省中考英语考试说明要求的语法体系，做成一个可计数、可练习、可复习的静态网站。

## 直接打开

```bash
open index.html          # 双击也行，无需服务器、无需构建
```

站点把数据内联进了每个页面，所以 `file://` 协议下也能正常工作（浏览器会拦截 ES module 的跨域加载，因此这里不用 module）。

## 为什么是「课标 + 河北省考说明」

河北各地市初中英语教材版本不统一（人教版 Go for it! 与冀教版均有使用），但**中考词汇与语法范围全省统一以课标与省考试说明为准**。因此本站以课标三级词汇表（约 1600 词，对应初中 7–9 年级）为词表基座，语法按课标三级语法项目组织，题型对齐河北省卷面——这样与任何版本教材都能对接。

## 卷面结构（2025 年起全省统一命题）

| 部分 | 分值 | 题型 |
|---|---|---|
| 第一部分 听力理解 | 30 | 听句子/对话/短文选择、听短文填空 |
| 第二部分 语言运用 | 25 | 完形填空 10 分 + **短文填空 15 分** |
| 第三部分 阅读理解 | 40 | 四篇阅读 + 任务型阅读 |
| 第四部分 情景交际 | 10 | **补全对话（2025 新增）** |
| 第五部分 书面表达 | 15 | 写作 |
| **合计** | **120** | |

相比改革前：**取消了单项选择和连词成句，新增情景交际（补全对话）**，从知识考查转向真实语境中的语言运用。本站的语法体系因此单列了「情景交际」一族。

## 学习闭环

```
词汇（1656 条）──→ 背单词（quiz.html）──→ 记忆库 ──→ 按遗忘曲线排下次

语法（39 考点）──→ 练语法（review.html）─→ 考点正确率 + 错题本
                        ↑
                 295 道题按考点与题型分组供应
```

- **背单词**：答完写入记忆库。忘了 → 10 分钟后再来；会了 → 按 ease 因子拉长间隔（1 天 → 3 天 → 7 天 → 21 天以上）。
- **练语法**：记录每个考点的累计正确率与具体错题；正确率低的考点浮到前面，可「专攻最弱考点」；答错的题进错题本，答对即移出。

## 篇章题与写作：冲满分的关键

河北卷 120 分里，**听、读、写共 95 分（79%）依赖语篇能力**，而纯语法题只能覆盖约 25 分。为此本站补充了：

| 模块 | 内容 | 对应卷面 |
|---|---|---|
| 完形填空 | 3 篇 × 10 空，记叙文 / 夹叙夹议，220–275 词 | 语言运用 10 分 |
| 阅读理解 | 16 篇 × 4–5 题（A/B/C/D 各 4 篇），应用文/记叙文/说明文/议论文 | 阅读第一节 30 分 |
| 任务型阅读 | 2 篇 × 5 题，简略回答 + 完成句子 | 阅读第二节 10 分 |
| 书面表达 | 8 种体裁范文 + 31 个高分句型 + 评分要点 | 书面表达 15 分 |

**语篇均为原创**：只复刻河北卷的题型结构、题材分布与难度梯度，不收录真题原文（规避版权与网络版本录入错误）。

## 盲填题（河北短文填空的固定考法）

河北「短文填空」15 空里含**盲填**——不给提示词，要自己填出冠词、介词或连词。本站为此：

- 语法体系单列**连词**一族（并列连词 + 从属连词），这是盲填的高频考点
- 题库标出 **35 道盲填题**（`blind: true`），在练语法页有独立的「短文填空盲填」筛选项
- 站内以**四选一**呈现（选项即候选连词/冠词/介词），便于即时判分与错题收集

## 发音说明

全站朗读均使用 **Edge TTS 预合成音频**（`en-GB-SoniaNeural` 英式女声，rate -10%，mono 32kbps），音色统一、专业，不依赖用户设备：

| 内容 | 条数 | 说明 |
|---|---|---|
| 课标词条 | 1656 | 词库与背单词页的 🔊 |
| 写作范文 / 亮点句 / 句型 | 64 | 写作模块的朗读 |
| 阅读原文 / 完形原文 | 随篇章 | 篇章页的「🔊 朗读全文」 |

音频由 `tools/gen_audio.py` 生成（需 `edge_tts` + `ffmpeg`），映射写入 `src/data-audio.js`（key = 朗读原文）。若某个文本没有预置音频，会自动回退到浏览器语音合成。

## 数据怎么来的

```
ECDICT 开源词典（770k 词条）
        │ 取 tag 含 zk 的 1603 条（= 课标三级词汇口径）
        ▼
tools/build_words.py
        │ ① 清洗释义（去 [计][化] 等领域标记、去噪义项）
        │ ② 人工校订 500+ 高频词的中学义项
        │ ③ 补派生词（better/usually/过去分词等）、英式美式拼写别名
        │ ④ 按词频分三档、按课标主题归入 17 个话题
        ▼
src/data-words.js                 构建器读取的数据源
```

语法与题库（`src/data-grammar.js`、`src/data-quiz*.js`）依据课标三级语法项目与河北省中考题型原创编写。

## 重新构建

```bash
node build-site.mjs             # 重新生成全部 HTML
python3 tools/build_words.py    # 仅重新生成词表（需要 ECDICT 的 ecdict.csv）
```

`build-site.mjs` 会把数据内联进页面，所以每次改数据都要重建。

## 数据校验

构建器会自动检查：

- 每个语法考点是否都有题目（缺题会打印警告并以非零码退出）
- 题型统计与考点覆盖数

## 部署

纯静态站，把整个目录（去掉 `tools/`、`src/`、`build-site.mjs` 亦可）上传到任意静态托管即可；GitHub Pages、Vercel、对象存储均可用。`.nojekyll` 已就位，避免 Pages 忽略下划线开头的路径。
